Jelaskan **$ARGUMENTS** kepada saya, seorang pemula Flutter, dalam Bahasa Indonesia yang sederhana. **Jangan mengubah file apa pun.**

Jika yang diminta adalah **file**:
1. Baca file tersebut.
2. Jelaskan gambaran besarnya dalam 2–3 kalimat: file ini untuk apa dan dipakai oleh siapa.
3. Jelaskan bagian demi bagian dari atas ke bawah, sambil menampilkan potongan kode pendek yang sedang dibahas.
4. Sebutkan hubungannya dengan file lain di proyek.

Jika yang diminta adalah **konsep**:
1. Definisi singkat dengan bahasa sehari-hari.
2. Analogi dari kehidupan sehari-hari.
3. Di mana konsep ini dipakai di proyek ini (sebutkan file dan bagian kodenya). Jika belum dipakai, katakan begitu.
4. Contoh kecil yang mandiri.
5. Kesalahan umum pemula terkait konsep ini.

Jika yang diminta kosong, tanyakan file atau konsep apa yang ingin dijelaskan.

Akhiri dengan **2 pertanyaan singkat** untuk mengecek pemahaman saya. Taruh jawabannya di bagian paling bawah dengan judul "Jawaban", supaya saya bisa mencoba menjawab dulu.
